## fingerprint with contact processing app
This is a maven built app without GUI.

## How to test
- Run the app (with netbeans or intellij, for example)
- Choose a fingerprnt image (*./fingerprint_with_contact.png* for example)
- Notice different steps images
    - reframing
    - without background
    - using of square and hexagonal grids
    - thresholding
    - squelletization
    - minutiae extraction
